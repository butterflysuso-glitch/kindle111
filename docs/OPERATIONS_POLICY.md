# KindleProject V2 · 运行与清理规则

- 默认零常驻、零自启动、零计划任务。
- 未经用户明确批准，不安装系统服务、修改注册表、代理、防火墙或启动项。
- 每个进程必须由用户手动启动，提供可定位和停止方式，测试结束主动退出。
- 删除/清理必须先只读核对精确路径及所属进程，不能使用无差别 `taskkill /IM python.exe /F` 或广泛递归删除。
- 不覆盖用户数据、已有 EPUB/AZW3、Kindle `documents` 中的文件。
- 不将私有书源、书籍正文、登录态、代理凭证或用户账号写入工程包。
- Kindle 固件、越狱、KUAL、恢复脚本与 rootfs 不允许由本项目自动修改。
- 单次书源更新属于运行时数据变更，不要求更新、编译或重新打包 Rust 程序。
- AI 无权创作并冒充原著缺章；OCR、网页取证必须在授权边界内执行。
- 正文完整性、来源真实性、官方目录一致性、人工审核是不同门禁，不能用其中一项替代另外三项。
